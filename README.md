# IndabaX_Equipe_18
Une plateforme d'éco-santé pour le Bénin. Via un Bot WhatsApp IA, les citoyens signalent des inondations ou déchets par note vocale (Fon, Français). Le système cartographie les alertes et calcule un indice de risque sanitaire pour prévenir les hôpitaux du paludisme et du choléra avant l'épidémie. Une solution inclusive qui sauve des vies



Comment lancer le projet et voir la démo

Notre solution intègre deux composants majeurs pour ce prototype :

### 1. Le Prototype Visuel (MVP Interactif)
L'interface utilisateur du Bot WhatsApp et du tableau de bord de la mairie a été entièrement générée et déployée. Elle est accessible en direct sans aucune installation requise :
**[Cliquez ici pour ouvrir la Démo EcosIA ]https://ecos-chat-nqqj5jlv.manus.space**

### 2. L'Algorithme de calcul (Backend Python)
Pour tester l'algorithme de calcul du risque sanitaire sur votre machine :
1. Clonez ce dépôt :
   ```bash
   git clone https://github.com[Ton-Pseudo-GitHub]/EcosIA-IndabaX-2026.git
   ```
2. Accédez au dossier :
   ```bash
   cd EcosIA-IndabaX-2026
   ```
3. Exécutez le script de simulation :
   ```bash
   python calcul_risque.py
   ```
