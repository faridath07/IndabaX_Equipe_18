# IndabaX_Equipe_18
GbéWé est une plateforme d'éco-santé pour le Bénin. Via un Bot WhatsApp IA, les citoyens signalent des inondations ou déchets par note vocale (Fon, Français). Le système cartographie les alertes et calcule un indice de risque sanitaire pour prévenir les hôpitaux du paludisme et du choléra avant l'épidémie. Une solution inclusive qui sauve des vies
